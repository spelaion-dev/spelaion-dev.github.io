What it does

A workbench for the hours you spend reading names, SQL and data: an explorer, an editor and a grid that holds millions of rows.

SSH tunnels that just work

Through any number of bastions, with an SSH agent, keys, passwords or 2FA. Kubernetes port-forwards and SOCKS or HTTP proxies too.

Safe AI agents

A built-in MCP server. Agents read behind read-only barriers, write only where you allow it, and every call is recorded on your computer.

Made for teams

Connections are plain files shared through git, never with a password inside. One that changes with a pull is not used until you have reviewed it.

Execution plans you can read

Explain a query on every engine and read its plan as an overview, a tree, a graph or the raw output, with findings that explain each problem.

Data in and out

Edit rows in the grid and apply them in one transaction. Import CSV, TSV, JSON and Markdown tables, and export results of any size.

A net under your slips

A DELETE without WHERE, a DROP or anything that writes to production asks before it runs. Read-only connections never change.

For AI agents

SpelaionDB is also an MCP server, so an agent can use the connections you choose, tunnels included, without ever seeing a password.

  • Agents reach only the connections you expose to them.
  • They only read, unless you let a connection take writes: one statement at a time, each in its own transaction.
  • DROP, TRUNCATE and a DELETE or UPDATE without WHERE are always refused.
  • One switch makes every agent read-only, and every call, run or refused, is recorded on your computer.

Install

The installers of the latest release. The app tells you when there is a new version, and installs it only when you ask.

Windows

  • Installer (.exe)
  • .msi

The installer needs no admin rights. It is not signed yet: if SmartScreen asks, choose “More info” and then “Run anyway”.

macOS

  • Apple Silicon (.dmg)
  • Intel (.dmg)

The app is not notarized yet: the first time, right-click it and choose “Open”.

Linux

  • AppImage
  • .deb
  • .rpm

For x86-64. Only the AppImage updates itself.

Coming from another client? SpelaionDB imports your connections from DBeaver, DataGrip, TablePlus, HeidiSQL, MySQL Workbench, pgAdmin and Beekeeper Studio. The installers include the spelaiondb command, the CLI and MCP server; on its own it is in the release's archives.
